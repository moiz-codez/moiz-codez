# Projects Section + Language Metrics — Design

Date: 2026-08-03
Branch: `feat/projects-section`

## Goal

Add two things to the GitHub profile README:

1. A **Projects** section showcasing all 8 non-profile public repos.
2. A **language metrics** visual showing the languages used across all
   public repos, generated as a custom SVG in the same terminal aesthetic
   as the rest of the README.

Both must match the existing README style: JetBrains Mono (embedded as
MJBMono), GitHub palette, dark/light `prefers-color-scheme` support,
shields.io flat-square badges (`24292f`), and a custom heading SVG.

## Context

The README (`README.md`) is a GitHub profile page built almost entirely from
custom Python-generated SVGs (see `scripts/` and `scripts/lib/svgkit.py`):

- `hello.svg`, `hd-portrait.svg`, `ascii.svg`, `hd-system-info.svg`,
  `neofetch.svg`, `hd-ecosystem.svg`, `system-map.svg`, `hd-timeline.svg`,
  `timeline.svg`.
- `neofetch.svg` is refreshed daily by `.github/workflows/stats.yml` which
  runs `scripts/generate_neofetch.py` and commits only when the file changes.
- The header badge row uses shields.io badges with `style=flat-square` and
  color `24292f`.
- Section headings are thin SVGs (`hd-<slug>.svg`) generated by
  `scripts/make_headings.py` — bold word + trailing rule line.

The 8 non-profile public repos (no GitHub descriptions set):
mojo-OS, lappu-lang, huffman-compression,
hospital-patient-record-management-system, guide-grad, glidemate-ogn,
2D-modular-game-engine, she_secure.

## Design

### 1. Projects section (markdown)

- Location: after `timeline.svg`, before the `## ❤️ A Note of Thanks & Inspiration`
  section.
- Format: a two-column HTML table grid (profile-readme convention), one card
  per repo, 8 cards in 2 columns × 4 rows.
- Each card contains:
  - Repo name in bold, linked to its GitHub URL.
  - A custom one-line blurb (written by the author, reviewable) describing
    the repo.
  - shields.io badges matching the header style:
    `?style=flat-square&logo=<lang>&logoColor=white` in color `24292f`
    (language badge) plus a star-count badge.
- Repos link to `https://github.com/moiz-codez/<repo>`.

### 2. Language metrics SVG (`lang-stats.svg`)

- New generator script `scripts/make_lang_stats.py` (one-off builder, same
  pattern as the other `make_*.py` scripts) plus a shared layout/content
  module `scripts/lib/lang_stats_build.py` so a refresh script and the
  builder never drift.
- Data source: GitHub REST API. List all public repos for `moiz-codez`, then
  fetch `/repos/{owner}/{repo}/languages` per repo and aggregate byte counts
  per language across all public repos.
- Rendering (neofetch-style panel, using `svgkit.py` primitives):
  - Width 940, `surface` rounded rect background.
  - Header line `LANGUAGE STATS — GITHUB, BY BYTES` (dim, letter-spaced) and a
    `FIG. 02` label at the right, with a `rule` line underneath — matching the
    `system-map.svg` header treatment.
  - Top languages as an animated horizontal bar chart (bars draw in with
    `svgkit.draw` / fade, stagger delays per row) with language name,
    percentage, and byte count.
  - Dark/light theme via existing `palette_css()`.
- New heading `hd-projects.svg` generated by adding `"projects"` to the
  `WORDS` list in `scripts/make_headings.py` and running it (this also
  regenerates the existing `hd-*.svg` files identically).
- The SVG is referenced in the README inside the Projects section.

### 3. Workflow

- New `.github/workflows/lang-stats.yml`, mirroring `stats.yml`:
  - Triggers: daily cron + `workflow_dispatch`.
  - Same `permissions: contents: write`.
  - Steps: checkout, set up Python, run `python3 scripts/generate_lang_stats.py`,
    commit + push only if `lang-stats.svg` changed.
  - `scripts/generate_lang_stats.py` mirrors `scripts/generate_neofetch.py`
    (idempotent: write only when content differs, print `no change` otherwise).
  - The workflow needs no API token for public repos (unauthenticated calls
    are fine for this volume).

### Files

- `README.md` — insert Projects section (grid + `lang-stats.svg` +
  `hd-projects.svg` heading).
- `scripts/make_lang_stats.py` — new, one-off builder.
- `scripts/lib/lang_stats_build.py` — new, shared layout + data fetch.
- `scripts/generate_lang_stats.py` — new, refresh entrypoint for CI.
- `scripts/make_headings.py` — add `projects` to `WORDS` (or a one-off
  heading script).
- `.github/workflows/lang-stats.yml` — new.
- `hd-projects.svg` — generated.
- `lang-stats.svg` — generated.

### Success criteria

- README shows a Projects grid with all 8 repos, each linked, with custom
  blurbs and flat-square badges.
- `lang-stats.svg` renders in the README in the same style as the other
  SVGs, with animated bars and dark/light support.
- Running `make_lang_stats.py` produces a valid SVG; the workflow is capable
  of regenerating it.
- Existing README layout intact; nothing else changes.
